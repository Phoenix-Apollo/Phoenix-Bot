Phoenix Bot - Current State Summary (May 12, 2026 - UPDATED)

What it is now
- Discord operations bot with Star Citizen tooling, interactive panel UI, and
  local-first data pipeline. Now includes multi-user conversation awareness for
  contextual group participation.

What changed recently
1) Local-first data ingestion
- Fetchers now check local files before any remote source for all supported
  datasets (commodities, trade, ships, weapons, components, mining, refinery,
  refinery stations, salvage, locations).
- Optional per-dataset local raw file and stats file overrides were added via
  env vars (see .env.example).

2) SQLite-backed dataset store
- Added persistent SQLite cache (`data/starcitizen.db`) for normalized datasets.
- Runtime load path now prefers SQLite -> data/*.json snapshot -> packaged
  resources.
- Updates now dual-write to both JSON snapshots and SQLite.

3) Refresh policy and remote call reduction
- Default refresh interval is monthly (`SC_REFRESH_INTERVAL_MINUTES=43200`).
- Startup skips live fetch when local/DB data is still fresh.
- Admin panel refresh now forces live update when requested.

4) Safer offline/blocked-source behavior
- If upstream is blocked/unavailable, existing local data is kept for all
  datasets instead of hard-failing or wiping useful values.

5) Ship weapon panel improvements
- Ship-weapon class filtering updated to match real weapon naming patterns.
- Weapon stats renderer expanded to show richer fields when present
  (burst DPS, alpha min/max, penetration, ammo/regen, spread, distortion,
  damage-type breakdown, health, pricing).

6) Conversation improvements - Context-aware tone matching
- Added KNOWLEDGE_QUERY intent type for factual questions (time, dates, definitions,
  facts, "how to" queries).
- TriggerEngine now routes time/date/definition/explanation patterns to KNOWLEDGE_QUERY
  instead of generic QUESTION.
- PersonalityEngine assigns NEUTRAL tone + low energy (1) to knowledge queries for
  informative, straightforward responses.
- SentenceGenerator now conditionally applies Deadpool tags:
  * SKIP tags: KNOWLEDGE_QUERY, COMPLAINT, CONFUSION (need sincere, informative tone)
  * APPLY tags: GREETING, CASUAL_CHAT, QUESTION, PRAISE, HYPE (get personality)
- Knowledge queries use natural prefixes ("Here's what I've got:", "Quick answer:",
  "Based on that:", "Good question — here's the info:") instead of narrator voice.
- Example: "what is the time" now returns "quick answer: Current local time: 1:49 PM"
  instead of "Red-suit narrator voice — ...unnecessary chatter... Sure thing. What are
  you trying to figure out?"

7) Dynamic sentence generation & personality learning from reactions
- SentenceGenerator now extracts vocabulary from high-scoring learned phrases to
  generate fresh variations while maintaining Deadpool tone.
- generateVariation() creates novel phrasings by:
  * Blending learned vocabulary into response templates
  * Injecting personality descriptors (e.g., "Full energy/chaos/vibes mode")
  * Preserving core meaning while varying word choice
- Variations occur 40% of the time to keep responses diverse and fresh.
- PhraseLearner now reinforces successful personality patterns: when a phrase gets
  upvoted (👍/✅), reinforceSuccessfulPattern() tracks which persona prefixes and
  Deadpool markers performed well.
- The bot learns Deadpool personality patterns from user reactions and gradually
  improves phrase generation over time.
- Result: Bot develops more personalized Deadpool voice that reflects what users
  actually enjoy, while preventing personality from becoming stale/repetitive.

8) Multi-user conversation awareness and contextual interjection
- NEW SERVICE: ChannelConversationService tracks real-time multi-user conversations.
- Bot now detects when 2+ users are actively discussing topics in a channel.
- Intelligently participates with contextual feedback, suggestions, or insights.
- Sentiment-driven response generation:
  * Questions: Offers helpful perspective and follow-ups
  * Problems: Empathetic troubleshooting and practical suggestions
  * Positive energy: Reinforcement and momentum-building
  * Neutral banter: Constructive additions and alternative angles
- Respects channel configuration and maintains conversation windows.
- Learns from group interactions via existing PhraseLearner system.
- Upvotes/downvotes on group replies refine future responses.
- Result: Bot feels like a natural community member, participating when relevant
  rather than staying silent or always requiring direct @mention.
